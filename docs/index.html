Общие правила и обозначения

Заклинания приведены по возрастанию уровня и по алфавиту внутри каждого уровня. Пометка ALT обозначает альтернативную версию официального заклинания. Эти версии предназначены для использования с материалами laserllama.

Новое время накладывания: при попадании (On Hit)

Заклинания со временем накладывания «При попадании» можно накладывать, когда вы в свой ход попадаете атакой оружием по указанной цели, подобно способности паладина «Божественная кара» (Divine Smite). На одну атаку нельзя потратить более одной ячейки заклинаний.

Новое время накладывания: 1 атака (1 Attack)

Заклинания со временем накладывания «1 атака» можно накладывать вместо одной атаки всякий раз, когда вы можете совершить атаку оружием в свой ход. Они не заменяют атаку заклинанием. Для их накладывания вместо провоцированной атаки нужна черта «Боевой заклинатель» (War Caster) или подобная способность.

Обозначения. В — вербальный компонент; С — соматический; М — материальный. Сл — сложность; КД — Класс Доспеха; БМ — бонус мастерства; ПО — показатель опасности; зм / см — золотые / серебряные монеты. Запись d обозначает кость: например, 2d6 — две шестигранные кости. Расстояния и объёмы сохранены в единицах оригинала: футы, мили, дюймы и галлоны.

Магус (Magus), Псион (Psion), Шаман (Shaman) и Сосуд (Vessel) — названия классов из исходного сборника. Игровые параметры и спорные формулировки оригинала сохранены; отдельные неоднозначности отмечены в квадратных скобках. Полный английский текст каждого заклинания доступен в раскрываемом блоке под переводом. Для поиска по документу используйте Ctrl+F или ⌘F.
